# ヒーロー画像生成記録

作成日：2026年10月27日

## 生成手段

imagegenスキルに従い、組み込みの `image_gen.imagegen` を使用。CLI・外部APIによる生成は使用していない。生成物はプロジェクト内にコピーして保存した。

## 保存先と用途

- `src/assets/generated/hero-chicken-desktop.png`：PCヒーロー用、横長。
- `src/assets/generated/hero-chicken-mobile.png`：モバイルヒーロー用、縦長。

元の5枚の商品写真は変更していない。横長画像は提供された `src/assets/masterchikinburger.webp` を参考画像として生成。縦長画像は生成済み横長画像を参考に、余白と商品位置をモバイル向けに生成した。

両画像とも、実店舗の料理を撮影した写真ではなく広告用の生成イメージ。写真内に文字・ロゴ・ハラール認証マークは含めていない。LPでは短い見出しをHTMLで重ねる予定。現段階ではサイト本体への組み込みは行っていない。

## 目視確認

- 黄色い背景、中央のバーガー、自然な影を確認。
- 上部に文字用の余白がある。
- 元写真を参考に、種のないバンズ、クリスピーチキン、上下のレタスを表現。
- チーズ、ベーコン等の追加具材、認証マーク、文字、架空の包装を含まない。
- 元の商品写真より衣・バンズの形が整った広告表現。実写の完全再現ではない。
- 横長と縦長は別生成のため細部には差異がある。各端末に片方を表示する前提。
- ブラウザ上の文字重ね・クロップ・表示品質は実装時に確認する。
