# HALAL MASTER CHICKEN SHIBUYA — 実装メモ

実装日：2026年10月27日

## 実装内容

- 既存Astroプロジェクトの初期ページをLPへ変更。
- 日本語 `/` と英語 `/en/` を共通コンポーネントから静的出力する構成。
- PC用・モバイル用の生成ヒーローを `picture` で出し分け。WebPと複数幅の変換はAstroの画像処理で行う。
- ヒーロー画像は即時読み込み、商品写真は遅延読み込み。画像寸法を指定。
- 商品写真5枚すべてをメニューへ配置。店頭未確認の価格は出力しない。
- 黄色・白・濃い文字を使ったポスター型ヒーロー、罫線主体のメニュー、ハラール案内、店舗情報、Instagram。
- スマートフォンの全画面ナビゲーションと下部固定の「メニュー」「Googleマップ」。セーフエリアと本文の下余白を考慮。
- 日英の本文・店舗情報・操作ラベル・alt。言語切替はクリック時の閲覧位置に合わせてアンカーを付ける。
- ナビゲーションはネイティブdialogを使用。Escapeでの閉じる操作、フォーカス復帰、背景スクロールの制御。
- PCかつ細かいポインター操作時にLenisを使用。GSAP tickerとScrollTriggerへ連携。
- GSAPで短い登場演出とPCヒーローの小さな拡大。長いピン留めや強制横スクロールは使用しない。
- 動きを減らす設定ではLenisと登場演出を停止。CSS上の情報は初期状態で可視。
- 日本語・英語メタデータ、Restaurant構造化データ、独自ファビコン。

## 未確認情報の扱い

店頭価格は全商品 `price: null`。確認済みの価格を数値で入力すると各商品の価格欄が表示される。ユーザー原稿にあるデリバリー価格は転記していない。

電話番号・デリバリーURLは `store.ts` で未設定。予約、電話、デリバリー、禁煙の案内は未確認のため画面に出していない。認証マーク・番号も追加していない。必要な情報が確定した際にデータと該当UIへ追加する。

## 公開URL

本番URLは `https://master-chikin-shibuya.pages.dev/` に確定。`src/data/site.mjs` で一元管理し、Astro設定、canonical、日英hreflang、OG画像、構造化データ、robots.txt、sitemap.xmlへ反映する。

以前の `PUBLIC_SITE_URL` 環境変数による指定は使用しない。ドメイン変更時は `src/data/site.mjs` の `siteUrl` を変更する。

SEO設定の詳細と再デプロイ後の確認項目は `SEO.md` を参照。ソースへの設定は実装済みだが、ビルド・公開先への反映・インデックス状態は未検証。

## ユーザー側で確認する場合の起動

プロジェクト指定のNode.jsは22.23.4以上。依存パッケージは既存のものを使用し、今回追加・更新していない。

```powershell
npm run dev -- --background
npm run astro -- dev status
npm run astro -- dev logs
npm run astro -- dev stop
```

実行する場合はこのプロジェクトのディレクトリで行う。今回こちらではサーバーを起動していない。
